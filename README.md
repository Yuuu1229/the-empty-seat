# The Empty Seat

An interactive story exploring perspective, friendship, and misunderstanding.

## Development

This project uses plain HTML, CSS, and JavaScript with no build step.

1. Clone the repository and switch to `main`.
2. Open `index.html` in a browser, or serve the directory with a local static server.
3. Edit `index.html`, `styles.css`, and `script.js`.

## Project structure

```text
.
├── index.html    # Page structure
├── styles.css    # Visual styles
└── script.js     # Interactive behavior
```
